# 山海策 · 灵脉

原创东方玄幻战棋 SRPG。纯静态网页，使用 HTML / CSS / Canvas / 原生 JavaScript，无构建步骤、无外部依赖、`file://` 可直接运行。

> **接手开发先读 [`HANDOFF.md`](HANDOFF.md)**：当前节点、下一步、代码地图、工程红线与踩坑清单都在那里。本 README 只讲「是什么、怎么跑、有什么」。

九条灵脉将枯，浊潮自海眼涌起。最后一位守脉人云策带着半卷残策下山，沿十六关路线收拢同伴、争夺阵眼，最终直面浊潮之眼。

## 运行

需要 Node.js 22+（本地服务器与 CDP 调试脚本使用内置 WebSocket；只运行游戏也可使用任意静态服务器）。

```bash
node dev/serve.js
```

浏览器打开 `http://127.0.0.1:4173/`。也可以直接打开 `index.html`，但推荐使用服务器，避免浏览器对本地文件的限制。

## 操作

- 点击我方单位，再点蓝色可达格移动，随后在行动菜单中选择攻击、法术、换装、占点、待机等。
- **攻击不消耗移动力**：原地出手后若还有剩余移动力，会回到移动模式继续走；每回合仍限一次攻击类行动。
- 拖动或点击地图查看敌我信息；顶部按钮可切换危险范围、战斗速度、系统菜单。
- 「结束回合」进入敌方阶段。
- 每章有 3 次悔棋（修罗难度为 0 次），可逐次回到之前的我方阶段开始，并完整恢复随机数状态。
- 中途退出、切后台或关闭页面会写入续战存档；再次进入选择「继续旅程」即可接续，读取后续战存档会被删除。

## 已实现内容

### 战役与叙事

- **16 章主线**：青岚山门 → 雾隐竹海 → 断桥古渡 → 赤砂关隘 →（分兵）→ 天柱废墟 → 浮槎渡海 → 沉城旧都 → 万脉渊 → 无字碑 → 浊潮之眼。
- **A/B 双线**：第 4 章末「焚脉 / 守脉」二选一，不可更改。A 线玄冰祭坛·血槲林·渡厄桥，B 线断魂谷·云梦泽·沧浪津，各带独立地图、同伴与剧情，第 8 章天柱废墟汇合。被放弃的三章在舆图上转为灰色的「未走之路」。
- **心结**：放弃的那条线化成同伴心结（命中 -5），与支援 A 级挚友了断；全部解开则终章全队 +5 命中 +5 必杀。
- **三幕剧情**：每章 intro / mid / outro 三段（`chapter.mids` 按回合触发第二幕，悔棋不重播），戏眼带震屏 / 闪白 / 压暗演出。
- **17 组羁绊支援**（C/B/A 三阶，相邻作战加深，专属对白 + 命中/回避/暴击加成），营地「关系」页画出零交叉关系网。
- **多结局**：按存活人数 × A 级羁绊 × 阵眼控制判定三档尾声（灵脉重燃 / 山河如旧 / 永夜）。
- **33 条山海图鉴**（妖兽 / 灵兽 / 精英 / 首领 / 遗迹五类），击破解锁；**英魂碑**记录阵亡者生平、遗言与传承。

### 战斗规则

- **20 名可用角色**、固定转职路线、武器耐久；经典永久死亡，云策阵亡即章节失败。三档难度分别调整敌军强度、经验与悔棋次数，另有与难度正交的**勇者模式**（敌军 ×1.15 / 无预测 / 无悔棋）。
- 命中 2RN、必杀 1RN、武器三角、追击、支援加成、地形与阵眼效果。
- **高低地形差**：章节带 `height` 层（0~2 海拔），高打低命中 +15 且射程 +1，低打高命中 -15；画面上高台有悬崖竖面与受光台面。
- **背侧判定**：单位带朝向，背刺命中 +15 / 暴击 +20，侧击 +5 / +10（只改命中暴击，不改伤害；法术不吃此判定）。
- **混合目标**：歼灭、坚守、占领、围攻、阵眼压制、撤退、Boss，以及村庄、宝匣、祠堂、增援、雾战、说得与召唤等支线事件。
- 敌方精英词缀（护盾 / 自愈 / 光环 / 狂暴）、双人连携、指挥技（号令 / 集火 / 坚守）、阵眼三阶驻守。
- **18 条法术**（五行各 3 阶 15 条 + 歌 3 条），相克 1.25 / 0.8，有限次数与 AOE，Boss 亦持法。
- **战中换装**：行动中可换武器（不耗移动力、不结束行动、每回合一次），换过后禁用换回；击杀敌军按概率掉落武器与道具。

### 成长与兵装

- 营地整备、商店、装备修理、转职、行囊与出战编成。
- **51 个职业**：多职业各有两条转职线（Lv.10 消耗脉印二选一），转职继承原职业技能（上限 2、先进先出、同名取大），个人技 ×2，熟练度按出手次数成长至 S。
- **兵装三层**：强化 +3（铁匠铺递增威力/命中/必杀）、进化（铁→钢→银/名器，保留强化等级、耐久刷满）、**传说武器 7 把**（Boss 小概率掉落 + 缘值保底）。
- **召唤三阶**（异兽 / 灵兽 / 神兽，场上 ≤2，三态指令）。
- **战略层分兵**：5A~7B 可从队中留守人员（云策必随行），出征页与战场双重校验，每章可调整一次。

### 呈现

- **打击感系统**（`js/juice.js`）：顿帧、震屏、闪白、粒子、击退、击杀慢动作与死亡定格（黑屏 + 名字 + 遗言），必杀四段式（推镜 + 立绘切入 + 慢放），可一键关闭或切「减少动效」。
- **技能演出**：15 条法术不写 15 段动画，而是「五行形态 × 三阶强度」组合——金/木/水/火/土/歌六种弹道形态，C/B/A 三阶只调粒子数、飞行时长与是否插立绘切入。`dev/fx-preview.html` 可不进战斗直接点着看。
- **音频**：BGM 场景管理器（标题曲《灵脉》程序化合成 59s 无缝循环）+ 31 个采样音效池，文件优先、合成兜底，缺素材不报错。
- 程序生成的水墨风 SVG 立绘、80 枚物品图标（武器 / 法术 / 药水 / 材料）、标题图与**绢本舆图**（鎏金路线、朱砂印、九脉灵丝、双线金框），全部为原创素材。

## 营地页签

编成 · 商店 · 打造坊 · 支援 · 关系 · 战报 · 英魂 · 图鉴 · 机制（30 条四组，文案与常量对齐）· 舆图 · 出征。

「舆图」把十六个章节节点铺在一张宣纸古图上，点节点看目标 / 支线 / 出击上限 / 行迹，当前章可直接「出征此章」。

## 开发与验证

改完代码必须四条全绿再提交：

```bash
node dev/test-logic.js          # 规则、数据与接线校验
node tests/formulas.test.js     # 公式回归（期望 1820 通过 / 0 失败）
node dev/smoke-boot.js          # 启动冒烟（期望：无引用错误）
node dev/smoke-boot.js sandbox  # 沙盒变体
```

改到特定区域时再加跑：

```bash
node dev/check-map.js           # 舆图体检：节点/连线/零交叉/五种进度渲染
node dev/check-rel.js           # 关系网零交叉
node dev/check-art.js           # 立绘与图标覆盖
node dev/gen-art.js             # 重新生成 assets/portraits 下的原创 SVG
node dev/cdp.js --reload --shot dev/shot.png
```

`dev/cdp.js` 需要浏览器以远程调试端口 `9222` 启动，并已打开本地游戏页面。它支持执行表达式、截图和收集控制台错误，便于回归战斗流程。

存档键（`SAVE_VERSION = 5`，读到 v4/v3 旧键会自动迁移并删除旧键；续战存档不迁移）：

- `shanhaice.save.v5`：战役进度
- `shanhaice.suspend.v5`：续战存档
- `shanhaice.settings.v5`：本地设置

## 素材说明

本项目未使用任何商业游戏素材。角色立绘、标题图、物品图标、舆图与界面纹样均由项目内脚本或 CSS/Canvas 绘制，可自由随项目使用。

美术缺口：下海六人（阿汐 / 敖绡 / 公输卯 / 陶无咎 / 沈砚 / 霜序）暂以 SVG 兜底，`dev/test-logic.js` 的 `PENDING_ART` 名单锁定这 6 人，补图后需从名单移除。BGM 其余场景（营地 / 战斗 / Boss / 剧情）仍待生成，文件按 `bgm_{scene}.m4a` 丢进 `assets/audio/bgm/` 即自动挂上。
