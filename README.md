# 山海策 · 灵脉

原创东方玄幻战棋 SRPG。纯静态网页，使用 HTML / CSS / Canvas / 原生 JavaScript，无构建步骤、无外部依赖。

九条灵脉将枯，浊潮自海眼涌起。最后一位守脉人云策带着半卷残策下山，沿八章路线收拢同伴、争夺阵眼，最终直面浊潮之眼。

## 运行

需要 Node.js 22+（本地服务器与 CDP 调试脚本使用内置 WebSocket；只运行游戏也可使用任意静态服务器）。

```bash
node dev/serve.js
```

浏览器打开 `http://127.0.0.1:4173/`。也可以直接打开 `index.html`，但推荐使用服务器，避免浏览器对本地文件的限制。

## 操作

- 点击我方单位，再点蓝色可达格移动，随后在行动菜单中选择攻击、治疗、说得、占点、待机等。
- 拖动或点击地图查看敌我信息；顶部按钮可切换危险范围、战斗速度、系统菜单。
- 「结束回合」进入敌方阶段。
- 每章有 3 次悔棋（修罗难度为 0 次），可逐次回到之前的我方阶段开始，并完整恢复随机数状态。
- 中途退出、切后台或关闭页面会写入续战存档；再次进入选择「继续旅程」即可接续，读取后续战存档会被删除。

## 已实现内容

- 9 章战役、12 张地图：第 5~7 章分 A/B 双线（A 线焚脉·追 / B 线守脉·守），第 8 章天柱废墟汇合；12 名可用角色，固定转职路线与武器耐久。
- 第 4 章末「追与守」二选一，选定后不可更改；两条线各有独立地图、同伴与剧情。
- 命中 2RN、必杀 1RN、武器三角、追击、支援加成、地形与阵眼效果。
- 歼灭、坚守、占领、围攻、阵眼压制、撤退、Boss 等混合章节目标，以及村庄、宝箱、祠堂、增援、雾战、说得与召唤等支线事件。
- 经典永久死亡；云策阵亡即章节失败。三档难度分别调整敌军强度、经验与悔棋次数。
- 营地整备、商店、修理、转职、行囊与出战编成。
- 战斗预测、伤害预览、危险范围、战斗日志、速度切换与自动续战。
- 程序生成的水墨风 SVG 立绘与标题图，全部为原创素材。

## 开发与验证

```bash
node dev/test-logic.js          # 规则、数据与公式校验
node dev/gen-art.js             # 重新生成 assets/portraits 下的原创 SVG
node dev/cdp.js --reload --shot dev/shot.png
```

`dev/cdp.js` 需要浏览器以远程调试端口 `9222` 启动，并已打开本地游戏页面。它支持执行表达式、截图和收集控制台错误，便于回归战斗流程。

存档键：

- `shanhaice.save.v4`：战役进度
- `shanhaice.suspend.v4`：续战存档
- `shanhaice.settings.v4`：本地设置

## 素材说明

本项目未使用任何商业游戏素材。角色立绘、标题图、图标与界面纹样均由项目内脚本或 CSS/Canvas 绘制，可自由随项目使用。
