# 《山海策 · 灵脉》剩余素材提示词（直接可用版）

> 用法：每条提示词 = 一整段，直接整段复制粘贴，不要拆句。
> **一致性三原则**（无论用哪个模型）：① 同一角色所有图共用同一段外观描述，一字不改；② 所有图带同一段风格锚定段；③ 模型支持垫图/参考图时，先用已归档的 `char_{id}_base.png` 作参考图，再生成该角色的表情/姿势变体——这是一致性最有效的手段。
> 文件名与目录对照见《待生成素材清单.md》，本文只给提示词。
