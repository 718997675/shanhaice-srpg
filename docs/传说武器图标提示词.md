## 二、生成与验收要点

- **比例 1:1、白底**：与既有单位图标规范一致，方便统一抠图流水线。
- **单件特写**：负面词已挡「多件兵器 / 人手」，若仍出多件，重抽或垫图。
- **辨识度**：每把的「记忆点」已写进描述（云状蚀痕 / 碧色奇花 / 三叉凝水 / 落日沉沙 / 看不见的薄刃 / 肋骨弯弓 / 断笔朱砂），缩小到 48px 仍应可辨。
- **套装统一**：7 张先后生成时，若某张风格漂移（如过亮、过卡通），把最满意那张作为垫图 + 固定 seed 重出。
- 生成完毕放入 `assets/icons/weapons/`，维护者会将其接入营地「打造坊 · 传说图鉴」与后续的行囊/装备界面。
