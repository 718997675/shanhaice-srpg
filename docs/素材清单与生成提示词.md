# 《山海策 · 灵脉》素材清单与 AI 生成提示词

> 用途：用户拿本文档让 AI（音乐/音效/绘图工具）生成素材，生成物归档后由开发侧挂接。
> 风格总纲：**国风 · 水墨 · 山海经 · 五行**。所有音频默认「安静处不腻、战斗处不燥」。
> 最后更新：2026-10-25。

---

## 0. 总则

### 0.1 目录与命名（生成后请严格按此归档）

```
assets/audio/
  bgm/    bgm_camp.mp3 / bgm_battle.mp3 / bgm_boss.mp3 / bgm_story.mp3   （必做 4 首）
          bgm_ch01.mp3 … bgm_ch12.mp3                                    （进阶，可选）
  sfx/    swing_light.wav / hit_flesh.wav / cast_fire.wav …              （必做 21 个）
```

- BGM：**mp3 必做**；ogg 可选（工具能导出就导，代码走 ogg→mp3 回退）。
- 命名全小写、下划线分隔，一个字母都不能差——代码按名取文件。

### 0.2 技术规格

| 项 | 规格 |
|---|---|
| BGM | mp3 192~320kbps，44.1kHz，**立体声**，单首 60~90s，**首尾无缝循环** |
| 音效 | wav，44.1kHz，16bit，**单声道**，每个 ≤0.5s（施法/阵亡类 ≤1.2s） |
| 美术（可选） | PNG 带透明通道，512×512，墨线 + 国风配色 |

### 0.3 生成后的交接

原始文件直接丢进 `assets/audio/` 对应目录即可，剩下的事开发侧做：
- wav 音效：响度归一化、去直流偏移、统一头尾静音（纯 Python 处理）；
- mp3 BGM：循环点检测与微修剪（能处理则处理，处理不了浏览器 `loop` 属性的小缝隙可接受）；
- 代码挂接：`<audio>` 池 + 触发时机（见每项的「触发时机」）。

## 1. BGM（必做 4 首）

> 音乐类 AI 工具（Suno / Udio / Stable Audio 等）通用技巧：把下方英文提示词粘进「风格/Style」框；歌词留空；生成后用工具自带的 Extend 接到 60~90s；提示词里已含 `seamless loop`，若成品循环仍有缝，把原始文件给开发侧修。

### 1.1 `bgm_camp.mp3` — 营地 · 整备

- **触发时机**：进入营地/整备界面；循环播放；被 BGM 切换时 1s 交叉淡入淡出。
- **中文描述**：空灵舒缓的国风环境乐。古筝或古琴主奏，远处一缕箫声，慢速，大量留白与混响，像雨后山谷。无人声、无鼓。听十分钟不腻。
- **提示词（粘贴用）**：
```
Ancient Chinese instrumental ambient, solo guzheng and xiao flute, ink wash
mountain atmosphere, slow 68 BPM, spacious reverb, gentle water drops,
no drums, meditative and hopeful, seamless loop
```

### 1.2 `bgm_battle.mp3` — 普通战斗

- **触发时机**：进入非 Boss 的战斗地图；循环；与营地 BGM 交叉淡切。
- **中文描述**：战棋战斗曲。二胡主旋律略带凄紧，琵琶轮指铺底，战鼓稳而急。紧张但有章法，像两军对峙而非追杀。五声音阶、小调。
- **提示词**：
```
Chinese tactical battle theme, erhu lead melody with minor pentatonic,
pipa tremolo, steady war frame drums, tense but restrained, 108 BPM,
heroic, no vocals, seamless loop
```

### 1.3 `bgm_boss.mp3` — Boss 战

- **触发时机**：Boss 单位登场（含二阶段变奏衔接）；循环。
- **中文描述**：巨大压迫感。编钟与太鼓定调，暗色二胡长音，低音弦乐持续轰鸣，像上古祭祀。速度不必快，要「重」。
- **提示词**：
```
Epic Chinese boss battle music, bianzhong ritual bells and taiko drums,
dark erhu drone, low strings rumble, 120 BPM, oppressive and monumental,
ancient sacrificial atmosphere, no vocals, seamless loop
```

### 1.4 `bgm_story.mp3` — 剧情 · 对白

- **触发时机**：章节剧情/对白演出时垫底；音量被自动压低（代码 duck）。
- **中文描述**：极简、情绪克制、绝不抢戏。古琴泛音点缀，大面积氛围合成器铺底，几乎无节奏。
- **提示词**：
```
Minimal Chinese ambient, sparse guqin harmonics, soft synth pad,
60 BPM, emotional and restrained, no percussion, background dialogue
music, seamless loop
```

## 2. 分工说明（2026-10-25 定：除 BGM 外全部开发侧直接产出）

用户决定不让其他 AI 做「我能直接做」的部分。经核定，分工如下：

| 素材类 | 产出方式 | 说明 |
|---|---|---|
| BGM 4~16 首 | **外部 AI 生成**（本文 §1 提示词） | 唯一外求项；没有音乐生成能力 |
| 音效 21 个 | **程序合成**（WebAudio 振荡器+噪声+包络，扩展现有 `js/audio.js`） | 零文件、file:// 必响；清脆合成器风而非录音棚级，先顶用。**挂接架构按「文件优先、合成兜底」设计，以后换成采样文件零成本** |
| 技能释放演出 | **纯代码**（粒子序列/符文阵/冲击波/立绘切入/震屏） | 15 条法术各一套，二期 G 框架内扩展 |
| 打击效果升级 | **纯代码**（刀光弧/拖尾/材质火花/微推镜） | render.js |
| 特效贴图（可选） | **文生图**（ImageGen，墨线国风，PNG 透明底 512×512） | 五系法阵/冲击波环/刀光；代码也能画，贴图为升级项 |
| 地形高度 / 背侧判定 | **纯代码**（height 层 + facing + combat.js 公式） | 见二期计划与 HANDOFF |

### 2.2 BGM 验收清单（生成后自查）

- [ ] 4 个文件齐全、命名与 §0.1 完全一致
- [ ] mp3 可直接播放，时长 60~90s
- [ ] 循环听 3 次以上无明显「断口气」感（接缝可接受开发侧修剪）
- [ ] 无人声、无歌词（提示词已含 no vocals，仍要自查）
- [ ] 战斗/Boss 两首不「燥」（长时间循环不烦躁）

> 进阶 12 章 BGM 不阻塞主线：先用 4 首必做版上线，章节曲按周目补。
