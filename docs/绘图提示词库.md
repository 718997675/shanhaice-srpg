# 《山海策 · 灵脉》绘图提示词库

> 用法：每条角色提示词 = 【外观描述】+【通用风格锚定段】。表情变体只改表情词、固定 seed 或垫图，保证同一人长相一致。图标只需胸像，底框由程序绘制，不要画框。

## 〇、通用片段

**立绘·风格锚定段（每条必带）**：
水墨国风，写实与写意结合，枯笔线条，宣纸底色，半身立绘，人物四分之三侧面，视线朝向画面右侧，靛蓝与朱砂点缀的东方奇幻配色，衣纹流畅带书法笔意，五官精致，高细节，纯色浅灰背景，无文字，无水印，无边框，单人，游戏角色设定稿

**图标·风格锚定段（每条必带）**：
游戏单位图标，单人胸像徽章，正面微侧，枯笔水墨线条，剪影化简洁，特征鲜明，居中构图，纯白背景，无文字，无水印，高辨识度，小尺寸可读

**通用负面词**：
文字，水印，签名，多余肢体，手指畸形，面部扭曲，多人，现代服装，3D渲染，照片级写实，低清晰度，边框

**一致性技巧**：① 每个角色先出「平静」版，满意后固定该图的 seed 或作为参考图（垫图），再生成受伤/决意/浅笑；② 全部角色共用同一段风格锚定段；③ 立绘出图比例 3:4，图标 1:1；④ 图标用白底生成，交付后由维护者抠图并加武器类型底框。
