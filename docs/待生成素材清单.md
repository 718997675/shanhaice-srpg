## 6.5 覆盖后的自检

```bash
node dev/pack-art.js --only portrait   # 立绘
node dev/pack-art.js --only icon       # 图标
node dev/pack-art.js --only full       # 全身
node tests/formulas.test.js            # 第 34 节会校验 20 人都有 jpg / hurt / icon
```

`dev/gen-portrait-jpg.js` 只在**该角色根本没有 jpg** 时才会跑——一旦你放了正式图，它不会去覆盖。
