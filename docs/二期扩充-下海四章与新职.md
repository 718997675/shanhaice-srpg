## 3. 职业：5 条新线 × 3 阶 = 15 个职业

| 基础 | 一转 A | 一转 B | 武器 |
| --- | --- | --- | --- |
| 潮汐使 tidecaller | 沧浪使 tidewarden（群护） | 深渊咏者 abysssinger（水攻） | 杖 |
| 潮刃客 waveblade | 斩潮者 tidecutter（单体重击） | 裂潮使 riptide（追击） | 剑 |
| 机关师 artificer | 傀儡宗 puppeteer（召唤） | 巧械师 machinist（远程） | 弓（弩） |
| 守墓人 gravekeeper | 引魂使 soulguide（治疗） | 葬海人 seaburier（破甲） | 符 |
| 锁链卫 chainwarden | 缚潮者 tidebinder（控制） | 断链客 chainbreaker（反击） | **链（新）** |

- 技能只用 `modsFor` 已支持的字段（hit / dmg / crit / avoid / avoidFlat / avoidOnNode / def / res / healBonus / hitVsArmor / critVsArmor / hitVsFlying / hitIfNoMove / hitIfMoved4 / defIfWounded / adjacentAllyHit / adjacentAllyAvoid / dmgPerSummon / summon / move）。**别写 `pierce` 这类没接线的字段**。
- 新武器类型 `chain`：射程 1~2、命中偏低、重量中等，不参与武器三角。

## 5. 硬约束（测试会卡）

1. 每章三幕：`intro` / `mids[1]` / `outro`，每幕 6~12 句、单句 ≤60 字、章内不重复、非全旁白、正文 ≥500 字。
2. 说话人必须在 `CHARS` 人名 ∪ `DIALOGUE_NPCS` 里。
3. 地图字符与实体坐标一一对应（`L`/`v`/`C`/`S`/`G`/`E`）。
4. 部署点 ≥ `deployCount`、可站立、不重复。
5. 新职业：`tier: 1` 必须有 `promote` 与 `promotes`，且指向真实 tier 2 职业。
6. 章节一律用 chapterId（`9`/`10`/`11`/`12`/`13`），章号显示走 `ch.no`。
