# 《山海策 · 灵脉》战斗演出立绘（全身）绘图提示词

> 本文件是《绘图提示词库.md》的**补充批次**：对话框/营地用的半身立绘已生成完毕，这一批专供**横版战斗演出**使用。两者不能互相替代，原因见第〇节。

## 〇、为什么半身立绘不能直接用于战斗演出

| | 半身立绘（已生成） | 战斗演出立绘（本批次） |
|---|---|---|
| 取景 | 胸口以上，3:4 | **头顶到脚完整入画**，2:3 |
| 背景 | 浅色纯色即可（放在对话框里） | **必须透明背景 PNG**（演出有场景层，会透视出底色） |
| 姿势 | 单一神情特写 | **站姿/受击/挥击三种动态姿势** |
| 用途 | 剧情对话、营地、图鉴 | 横版战斗演出两侧对峙 |

判定标准：生成的图**能看到完整的脚和武器**，就是演出立绘；只到腰或胸口、带底色，就是对话立绘。

## 一、规格要求（交付前自查）

1. **尺寸**：宽 ≥1600 × 高 ≥2400（2:3 竖构图），单张 ≤3MB
2. **背景**：透明底 PNG（不要白底、不要灰底、不要投影）
3. **构图**：人物占画面高度 85%~92%，**双脚完整、不贴边不裁切**，水平居中
4. **朝向**：**一律面朝画面右侧**（敌方单位由程序水平镜像，不用反向生成）
5. **三姿势**（每人）：
   - `base` 待机：双脚与肩同宽站稳，武器自然持握，神情平静
   - `hurt` 受击：身体后仰，一手护挡，神情痛楚，衣摆被气流掀起
   - `attack` 挥击：武器高举或突刺，身体前倾，衣发飞扬（推荐做，最低配可只做 base+hurt）
6. **骑乘与飞行单位特别约定**：
   - 白鹭（枪骑）：**画"马下持枪站立"**即可，程序不画马；若愿意画骑马，必须人马都完整入画（可选升级，非必须）
   - 云翎（羽人）：**双翼必须完整入画**（展开或收翼均可），翼是她全身最重要的识别点

## 二、通用片段

**全身立绘·风格锚定段（每条必带）**：
水墨国风，写实与写意结合，枯笔线条，宣纸质感，全身立绘，人物正面微侧、视线朝向画面右侧，双脚稳稳站立完整入画，武器持握清晰，靛蓝与朱砂点缀的东方奇幻配色，衣纹流畅带书法笔意，五官精致，高细节，透明背景，无文字，无水印，无边框，无投影，单人，游戏战斗设定稿

**姿势指令段（接在锚定段后）**：
- base：`全身站姿，双脚与肩同宽稳稳站立，武器自然持握于身侧，神情平静坚定`
- hurt：`受击姿态，身体向后仰，单手护挡在身前，神情痛苦，衣摆被气流掀动`
- attack：`攻击姿态，武器高举过头/向前突刺，身体前倾，衣发被风扬起，充满力量感`

**全身立绘·负面词（每条必带）**：
文字，水印，签名，边框，背景，投影，截断，裁切，双脚出画，肢体畸形，多余肢体，手指畸形，面部扭曲，多人，现代服装，3D渲染，照片级写实，低清晰度

**一致性技巧（关键，决定这一批图能不能用）**：
1. **垫图锁脸**：在即梦/豆包里上传该角色**已通过的同角色半身立绘**作为参考图，再输入全身提示词——这是保证"全身还是同一个人"的最有效手段
2. **姿势派生**：同一角色 `base` 满意后，用 `base` 图作垫图，只换姿势指令段，生成 `hurt` 和 `attack`
3. 全部角色共用同一段风格锚定段，不要逐条改写
4. 出图后三查：脚完整 / 武器正确 / 脸是同一人；任一不过关就换 seed 重出，不要将就

**竹妖**：竹节身躯的妖物，中空腹腔透出幽光，竹叶为须，雾气缭绕，阴冷。要点：竹节躯干全貌、根状足入画。
**水鬼**：浮肿人形水妖，滴着黑水，指间有蹼，眼窝空洞，湿地爬行感。要点：滴水、蹼足、佝偻全身。

## 五、敌兵（可选，最低配不做）

最低配置下，战斗演出中的敌兵用「放大的地图图标 + 斩击特效」兜底即可，不阻塞开发。
若追求质感，补 10 张（5 职业 × 2 变体，各 base 一姿势）：
妖兽（山猫型/狼型）、浊兵（刀兵/盾兵）、咒徒（瘦高/佝偻）、傀儡（完整/断臂）、兽骑（轻骑/重甲骑）。外观沿用《绘图提示词库.md》第三节描述，只把"胸像徽章、白底"改为"全身、透明底、面朝右"。
